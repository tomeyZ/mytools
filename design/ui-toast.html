「已复制」提示条配色对比

4 个选项 × 浅色 / 深色两种主题，都放在真实上下文里（顶栏 + 时区页头部），位置、尺寸、字号与线上完全一致。

关键前提：这套令牌的 --accent 在浅色下是靛紫 #4f46e5，在深色下会变成青色 #22d3ee。

结论：不建议换色相，绿是对的；要动就动饱和度

  • 别改成紫色（B）。提示条是「结果反馈」，该用语义色；紫色是「品牌强调色」。混用之后，成功与失败的区别就从「绿 vs 红」退化成「紫 vs 红」——两个都像品牌色，只能靠记忆分辨。
  • 更要命的一点：这套令牌的主色在深色主题下不是紫、是青 #22d3ee。改完之后同一条提示在浅色下是紫、深色下是青，跨主题反而更不统一——你想统一的那个东西并不存在。
  • 而且主色已经在这套界面里到处占用：侧栏选中项、主按钮、焦点环、时区徽章、顶栏主题切换的选中块。提示条再用它，等于「所有东西都在强调」= 都不强调。
  • 推荐 D（墨绿）：绿色语义、图标、位置、尺寸全不动，只把饱和度从 80% 压到 45%。你的不适感基本来自「这个绿太亮」，而不是「这个绿不对」——那就在饱和度上解决，一行 CSS 的事，风险最低。
  • A（现状）也完全成立，比改紫强得多。这套界面里唯一的高饱和色块就是它，说难听是刺眼，说好听是「一眼就能看到」——顶部 62px 的位置离操作点本来就远，这个存在感是有用途的。
  • C（软底）可以但要认清代价：它在浅色下会浮在同一白底的 hero 卡片上方，只剩阴影撑层级，基本糊进页面（见上面 C 的浅色那张）。它是「安静派」的正解，但这一页要的是「确认反馈」，我担心 2.6 秒里被漏看。
  • 顺带一个真实瑕疵：TimeTool 提示条里的勾图标是写死的 SVG，没有条件分支——现在「复制失败」弹出来的也是绿色勾。不管最后选哪个方案，这个都建议补上叉图标。另外其余 6 个页面（MD5 / AES / RSA / 文本 / IP / JSON）的提示条压根没有图标、只有文字，要统一的话得一起补。
