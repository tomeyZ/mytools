开发工具 · 界面改版设计稿

基于当前 v1.1.3 的功能结构（7 个工具）重新设计。四个方向都能一比一还原现有功能，只是视觉语言与信息密度不同。 每个设计稿都按 1180×720 的真实窗口比例绘制，内容区已用「时区转换」页做样例。
先看第一个「★ 融合演示」——那里把 A/B/C/D 合并成了三个可以实时点击的开关；后面四个是各自的静态大图。

★ 融合演示｜三个开关，一套代码

推荐落地方案可直接点着体验

你的理解是对的：A 是底子，右上角做主题切换（切深色就是 B、切毛玻璃就是 C），左上角加一个折叠按钮（收起侧栏就是 D 的形态）。关键点是这三个不是互斥的四个方案，而是三个正交开关，CSS 变量一套搞定。

  • 右上角 浅色 / 深色 / 毛玻璃 分段切换 —— 只换一套 CSS 变量，结构完全不动
  • 左上角 折叠按钮 —— 侧栏 218px ↔ 68px，过渡动画已有
  • 两者可任意组合：深色 + 折叠、毛玻璃 + 展开……共 6 种形态
  • 下面直接点着试试，窗口会实时切换，注意它是同一个 DOM，没重载

A · Clarity｜现代浅色

推荐日常使用改动可控

沿用现在的浅色底，但把整套视觉收敛到「一个中性灰阶 + 一个强调色」。去掉 emoji 图标、统一圆角与描边、结果区不再用大块虚线占位。

  • 全局字体改为无衬线（原来是思源宋体）——这是观感差异最大的一处
  • 强调色统一为 靛蓝 #4F46E5，取代现在的绿/蓝/橙/紫四色混用
  • emoji 图标换成 线性 SVG，菜单按「时间 / 加密 / 数据 / 网络」分组
  • 时区选择从独占一行收进页头右侧，省出一条横向空间
  • 空结果由虚线大框改为低对比度占位行，有结果时变高亮条

B · Terminal｜深色专业

长时间盯屏开发者向

深色底 + 青绿点缀，所有数值走等宽字体。适合每天开一整天、旁边就是编辑器和终端的人，观感上更像一把「正经的工具」。

  • 底色 #0E1116，卡片用 1px 描边区分层级，几乎不用阴影
  • 时间/时间戳/哈希结果统一等宽字体 + 等宽数字，防止跳字
  • 强调色 青色 #22D3EE，语义色用绿/黄，不用红色大色块
  • 结果区分「空」用虚线框、「有值」用青色描边——状态一眼可辨

C · Aurora｜毛玻璃卡片

最好看适合内部分享截图

渐变主视觉 + 毛玻璃卡片 + 大圆角。视觉冲击最强，把「当前时间」做成一张渐变色 hero 卡，工具感弱一些、产品感强一些。

  • hero 卡使用 靛蓝→紫→粉 渐变，是整页唯一的强视觉重心
  • 卡片 半透明 + backdrop-blur，背景是三团柔和光晕
  • 圆角放大到 18px，阴影变柔变散，不再有硬描边
  • 注意：毛玻璃在低配机上有渲染开销，Wails 里建议实测帧率

D · Compact｜窄导航栏

省空间保留品牌绿

左侧收成 66px 的纯图标栏，横向空间全部让给内容区。主色延用现在的品牌绿，改动方向偏「结构」而不是「换皮」。

  • 侧边栏从 220px 压到 66px，内容区宽度 +150px
  • 图标栏深色，内容区白色，形成清晰的左右分区
  • 工具名通过 hover tooltip 显示；7 个工具用图标完全够辨识
  • 主色 #0F9D63，比现在的 #42B983 更深、更沉稳

横向对比

下表是四个静态方向的对照。注意：A/B/C 是同一套变量下的三个取值，D 是独立的布局开关，实际落地是它们组合成的一个界面。

方向视觉感受改动量适合场景
A · Clarity干净、克制、像 Linear / Vercel 内部工具中（改样式 + 换图标）通用，最稳妥的默认选择
B · Terminal冷峻、专注、像 JetBrains 系中（需要维护两套色板）团队都是后端/运维，长时间使用
C · Aurora精致、有产品感、截图好看大（毛玻璃 + 渐变 + 圆角体系）需要对外展示、给人「这工具挺讲究」的印象
D · Compact紧凑、信息密度高、结构清晰中（要重做侧边栏交互）小屏笔记本、或后续工具数量继续增加
结论：不用在四个方案里选一个。A / B / C 不是三套皮肤，是同一套 CSS 变量下的三个取值； D 也不是第四套，而是「侧栏折叠」这一个独立开关。所以最终就做一个界面： 以 A 为默认值，右上角切深浅（= B）、切毛玻璃（= C），左上角折叠侧栏（= D）。见 ★ 融合演示。

落地路线（按性价比排序）： ① 全局字体从思源宋体换成无衬线 → ② 在 style.css 里定义一套 CSS 变量（颜色/圆角/阴影/字体）， 替代现在散落在各 .vue 里的硬编码色值 → ③ 侧栏 emoji 换成 SVG 图标 + 按功能分组 → ④ 结果区大块虚线占位改成占位行 → ⑤ 顶栏加主题分段控件 + 折叠按钮，主题写进 localStorage 持久化。

几点实现提醒：① 主题切换用 data-* 属性 + CSS 变量，不要在每个组件里写 v-if 判深浅色， 否则 7 个工具页要改 7 遍；② 毛玻璃（backdrop-filter）在 Wails/WebView2 上开销明显， 建议做成一档可选主题而不是默认；③ 折叠宽度用 grid-template-columns 过渡，比 width 更平滑； ④ 侧栏折叠后一定要给图标加 title，否则工具名就找不到了。
